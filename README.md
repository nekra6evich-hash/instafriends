# FollowScope PWA

Локальное Android-friendly приложение для ручного импорта и сравнения JSON/CSV-снимков подписчиков и подписок.

## Локальный запуск
1. Установите Node.js 20 или новее.
2. В папке проекта выполните `npm install`.
3. Выполните `npm run dev`.

## Сборка
`npm run build` создаст папку `dist`.

## GitHub Pages
Загрузите проект в GitHub, включите GitHub Actions или соберите `dist` и опубликуйте ее. В `vite.config.js` уже задан относительный base.

## Установка на Android
После публикации откройте сайт в Chrome и выберите «Добавить на главный экран» / «Установить приложение».

Приложение не подключается к Instagram, не принимает пароль, cookies или токены и хранит данные в localStorage текущего браузера.
